# My app

**Domain:** Student assignments and personal coursework planning

**User story:** As a student, I want to add tasks, view my tasks, and mark them as completed, so that I can keep track of my assignments.

**What the user types or picks:**

- A task title, such as "Finish INFO 430 schema"
- A due date
- A filter for all, open, or completed tasks
- A checkbox-style button to mark a task complete or incomplete
